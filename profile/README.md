# VecturaDB

Vector database compatible with the Chroma API, bringing Chroma Cloud's features to open source.

```bash
pip install VecturaDB
docker run -p 8000:8000 -v ./data:/data ghcr.io/vecturadb/vecturadb:preview
```

| Repository | |
|---|---|
| [VecturaDB](https://github.com/VecturaDB/VecturaDB) | The database. Hybrid search, sparse vectors and BM25 are already here. |
| [vecturadb.org](https://github.com/VecturaDB/vecturadb.org) | The website: [vecturadb.org](https://vecturadb.org). |

VecturaDB was forked from the open-source [Chroma](https://github.com/chroma-core/chroma) project. It is not affiliated with Chroma.
